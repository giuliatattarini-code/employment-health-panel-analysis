# Employment Health Panel Analysis

Can improving employment conditions improve workers’ health and well-being?  
This repository presents a reproducible longitudinal panel-data workflow using SOEP data and fixed-effects models in STATA 19.

## Overview

This repository contains a simplified analytical workflow for studying the relationship between employment conditions and health outcomes using longitudinal panel data.

The project showcases:
- data cleaning and harmonisation
- variable construction & sample selection
- panel data modelling and visualisation
- reproducible analytical workflows

The repository is intended as an illustrative and portfolio-oriented version of the workflow used in related academic research projects.

---

## Data

- Source: SOEPv39 (German Socio-Economic Panel)
- Structure: longitudinal panel data
- Unit of analysis: individual-year observations

Due to data protection restrictions, SOEP data are not included in this repository.

---

## Methods

Main analytical components include:
- longitudinal data processing
- construction of employment-related indicators
- fixed-effects panel regression models
- visualisation
